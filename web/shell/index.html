The Lost Vikings

The native port of the 1992 DOS game, compiled to WebAssembly. Your game files stay in this browser (IndexedDB) and are never uploaded to any server.

Saves & backup

In the game, F2 saves the whole game state and F3 loads it; the slot (1–9) is SAVE SLOT / LOAD SLOT in the F1 menu.

    Backup

    Everything stored here as one .zip — settings, key bindings, save states, and optionally the game files — to keep a copy or to move to another browser. Importing adds to what is stored and replaces files of the same name.

    Advanced

    Stored settings: none.

    Co-op: one game controller per player (press a button on each after Play); the keyboard plays with the first one. Player 2 takes a viking even without a controller — play alone with 1.

    F1 options · F2 / F3 save / load · F11 fullscreen · keys as in the DOS game (rebindable in vikings_keymap.cfg)

    Source · Requires a browser with WebAssembly threads (current Chrome, Edge, Firefox, Safari).
